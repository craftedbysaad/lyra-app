Install in a minute

Android

  1. Download the .apk from the latest release.
  2. Open it and allow "Install unknown apps".
  3. New versions install over the old one; your music stays.

iPhone

  1. Download the .ipa from the latest release.
  2. Install it with Sideloadly using your Apple ID.
  3. With a free Apple ID, re-sign it every 7 days.
